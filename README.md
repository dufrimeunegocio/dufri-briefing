# Dufri Briefing Hub

Crie um sistema web moderno e profissional de briefing para clientes da agência Dufri Meu Negócio.

IMPORTANTE: nesta primeira etapa, crie apenas a interface visual e a navegação do formulário. Não configure banco de dados, autenticação, Supabase ou integrações externas ainda.

IDENTIDADE VISUAL:

Azul principal: #123C6B

Ciano: #37C6D0

Verde: #7DBA84

Fundo branco e cinza claro

Utilize a logo enviada como identidade principal

Design moderno, profissional, limpo e minimalista

Não deixar com aparência genérica de inteligência artificial

Totalmente responsivo, priorizando celulares

ESTRUTURA:
Crie uma tela inicial de boas-vindas com a logo, uma mensagem curta explicando que o cliente irá preencher as informações necessárias para iniciar a criação do seu site e um botão “Começar briefing”.

Após clicar, o usuário deve responder uma pergunta por vez, sem mudar de página ou URL. O formulário deve funcionar como um sistema interativo com etapas internas.

Em todas as telas do formulário:

Exibir barra de progresso no topo

Mostrar a etapa ou progresso atual

Uma pergunta principal por vez

Botão “Continuar”

Botão “Voltar” a partir da segunda pergunta

Campos grandes e fáceis de usar no celular

Não permitir avançar visualmente sem responder perguntas obrigatórias

Criar transições suaves entre perguntas

Por enquanto, crie apenas a estrutura visual completa e a navegação. Não implemente banco de dados ou funcionalidades externas.

Crie uma experiência profissional, simples e rápida para clientes que chegam através do WhatsApp e precisam preencher um briefing para criação de site.
